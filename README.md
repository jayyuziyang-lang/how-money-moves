# 钱是怎么跑起来的

一本从零开始的金融世界说明书 · 2026 年 8 月版

26 章，约 10.5 万字，分四个层级：

| 层 | 主题 | 回答的问题 |
|---|---|---|
| 01 地基篇 | 钱到底是什么 | 你钱包里那串数字，凭什么能换来一碗面 |
| 02 管道篇 | 这台机器怎么转 | 钱怎么被造出来、怎么流动、怎么定价 |
| 03 天气篇 | 潮汐、风暴与泡沫 | 风险如何被标价、被放大、被转移 |
| 04 落地篇 | 你在其中怎么活 | 这些跟你的钱包有什么关系 |

## 在线阅读

打开 `index.html` 即可，无需构建、无需联网（网络字体会优雅降级到系统字体）。

## 目录结构

```
index.html        封面与全书地图
level-1..4.html   四层正文（由 build.mjs 生成，不要直接编辑）
glossary.html     附录：术语速查、2026 数据快照、原则清单
assets/style.css  设计系统
assets/app.js     阅读器交互（夜读模式、字号、进度、J/K 跳章）
content/ch-*.html 各章正文片段（编辑这里）
build.mjs         把 content 片段组装成 level 页面
lint.mjs          文风与规范体检（禁用词、破折号、组件、标签闭合）
check.mjs         全站链接与结构校验
BRIEF.md          写作总纲，含反 AI 腔守则与 2026 事实速查表
```

## 修改流程

```bash
# 编辑 content/ch-XX.html 之后
node build.mjs   # 重新生成四个层级页面
node lint.mjs    # 文风与规范体检
node check.mjs   # 链接与结构校验
```

## 数据口径

所有数据截至 2026 年 8 月，来源包括中国人民银行、美联储、欧洲央行、国际金融协会（IIF）及公开财经报道。
